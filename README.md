# Anniversary Bot (@Anniversaryhbot)

Telegram bot that tracks birthdays/anniversaries and reminds you 1 day before and on the day.

## Setup
1. Message @BotFather on Telegram → /newbot → set username to Anniversaryhbot → copy the token.
2. Locally: `npm install`, copy `.env.example` to `.env`, paste your token in, then `npm start`.
3. Push to GitHub:
   git init
   git add .
   git commit -m "Initial commit"
   git branch -M main
   git remote add origin https://github.com/<you>/anniversary-bot.git
   git push -u origin main
4. On Railway: New Project → Deploy from GitHub repo → select this repo → add BOT_TOKEN in Variables tab.
